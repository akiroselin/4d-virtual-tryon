# 物理仿真原理（中文导读）

本文从代码出发，解释这个项目里的布料仿真是怎么工作的。重点放在主路线：
Anny 人体上的连续 T 恤 / 百褶裙壳仿真，即 `anny_cloth4d_simulation.py`、
`neuralclothsim_dynamics.py`、`unified_cloth4d_scene.py` 这条链。英文设计文档
（`docs/*_2026.md`）是权威来源，本文是读它们的地图。

> 一句话：服装 = 一张**不可变的材料度量**（2D 版片或曲面静止形状）+ 一个
> **可变的 3D 嵌入**。物理只改变嵌入，从不改变材料本身。

---

## 1. 两种表示：制造图集 vs. 仿真壳

| 表示 | 存什么 | 谁用 |
|---|---|---|
| 制造图集（manufacturing atlas） | 2D 版片、缝线接口、布纹方向、尺寸 | 版型、生产、材料坐标 |
| 仿真壳（simulation shell） | 一张连续的三角网格中面，已经“缝好” | 动力学 |

早期做法是把前片、后片、袖片分开放到人体周围，再用缝线弹簧拉到一起。实测这样
会产生腋下鼓包、接缝处 p95 边长变化 +10.7%、11 个穿插面。现在的做法
（`implicit_shell.py`）是：

```
φ_g(x) = d_body(x) − r_ease,   x ∈ 躯干 ∪ 上臂区域
```

在人体 SDF 的外偏移等值面上直接提取一张连续的 T 恤壳。它必须满足：

- 1 个连通分量、无非流形边、亏格 0；
- **恰好 4 条边界环**：领口、下摆、左右袖口（欧拉示性数 −2）；
- 顶点和三角内部采样点都不穿入人体。

缝线信息保留为“出处”，运行时没有缝线弹簧。连续壳的结果是 p95 边长变化
+1.6%，穿插面为 0。

> 本次修复：衣长超过裆部时，下摆会分成绕两条腿的两个环，壳就不再是 T 恤。
> `_crotch_height` 现在把下摆限制在裆部以上 3 cm。

百褶裙（`pleated_skirt.py`）是一个环形壳，有腰和下摆两条边界。压烫的褶直接
写进**静止曲率**，所以褶是“无应力”的。弯曲能只惩罚曲率的**变化**，否则仿真
会把褶熨平。

## 2. 状态与时间积分

每个布料顶点的状态是 `(材料坐标 ξ, 位置 q, 动量 p = M v)`。

- 集中质量：`m_i = ρ_A · A_i`。`A_i` 是相邻三角形静止面积的 1/3，面密度
  `ρ_A`（kg/m²）来自面料卡，例如棉 0.170、羊毛 0.235（`measured_materials.py`）。
- 基础步进是辛欧拉（kick-drift），保持质量与材料标签不变：

  ```
  p_{n+1} = p_n + dt · F
  q_{n+1} = q_n + dt · M⁻¹ p_{n+1}
  ```

- 实际运行时，保守力（壳弹性、缝线、重力、人体与层间接触势）被组装成一个
  **增量势能**，在 `q_{n+1}` 处做带信赖域和线搜索的非线性求解
  （`phase_hamiltonian_iterations`，信赖半径约 3 mm）。这本质上是变分隐式
  欧拉。非保守项（阻尼、学习残差、运动体惯性力）作为显式“端口”加入。
- 默认 `dt = 4 ms`，每帧 3 个子步，加速度上限 120 m/s²，速度上限 3 m/s。

## 3. 本构：Kirchhoff-Love 薄壳 + Hyper-NODE

**膜（拉伸 / 剪切）**：对每个三角形，

```
F = Ds · Dm⁻¹         （当前边矩阵 × 静止边矩阵的逆）
C = Fᵀ F
e_经 = ½(C₀₀ − 1),  e_纬 = ½(C₁₁ − 1),  e_剪 = C₀₁,  e_面 = √det C − 1
```

这些量与刚体运动无关（frame-indifferent）。

**弯曲**：作用在相邻两面的铰链上，度量的是面法向夹角相对**静止曲率**的变化，
权重用标准的材料空间对偶面积。

**Hyper-NODE**（`hypernetwork_kirchhoff_love.py`）：

- 超网络输入材料点 `ξ`、版片、场景材料隐变量，输出该点一个**局部神经 ODE**
  的全部参数。
- NODE 把应变映射为能量导数。从 `e` 和 `0` 两个初值积分同一个 ODE 再相减，
  保证零应变时响应为零且符号正确。再用三点 Gauss-Legendre 积分得到非负能量。
- 所有线性层做谱归一化，保证 Lipschitz 有界。
- 一个全场景标量把未标定的模量缩放到目标 p95 加速度，整次 rollout 固定，
  不逐帧归一化。量级过小时报告 `constitutive_recalibration_required`。
- 应变限制：超过最大拉伸 / 压缩的 80% 后，加一个屏障势。

## 4. 外力“端口”

| 端口 | 形式 | 角色 |
|---|---|---|
| 重力 | `m g`，g = (0, −9.81, 0) | 外势 |
| 速度阻尼 | `−c m v_rel` | 耗散（Rayleigh） |
| 弯曲模态阻尼 | 只阻尼 `v − LB 低通(v)` 这部分高频分量 | 耗散，用 Laplace-Beltrami 扩散实现，与网格分辨率无关 |
| 运动体惯性力 | `−k m a_body`（在随体参考系里） | 控制端口：身体加速把动量传给布料 |
| E(3) 学习残差 | 先做 LB 扩散，加速度上限 5 m/s² | 学习残差；不允许替代本构 |
| 缝线 / 饰条 | 弹簧 + 阻尼（只在图集后端使用） | 保守 + 耗散 |

每个端口的功率都记入一个“广义流账本”（`generalized_flow.py`），因此能量从
哪里进、从哪里散都可以审计。

## 5. 接触

**人体接触**（`_resolve_contact`）：

1. 用人体 SDF 求间隙：`g = φ_body(x) − h`，h ≈ 3 mm。
2. 事件检测：`g` 的零交叉被括区间定位（`dynamic_events.py`）。步内穿越会
   触发截断并重启子步，不能静默接受。
3. 位置：沿法向推出 `relu(h − g)`。
4. **动量重置**：去掉相对人体的入射法向速度；切向按库仑摩擦衰减。摩擦方向
   在局部 SO(2) 切平面标架里处理（gauge contact），μ 来自面料卡，例如棉
   0.22、羊毛 0.42。
5. 三角面采样点再投影一次，防止肢体从三角形中间穿过。

**层间接触**（T 恤 vs. 裙子，`unified_cloth4d_scene.py`）：两件衣服共享一个
物理时钟，T 恤下摆与裙腰之间的采样点间隙势进入同一个增量势能。导出时另有
一个只影响显示的“层序保护”，最多移动 0.66 mm，会在 `physicsAudit` 中如实
记录。

## 6. 度量投影（约束）

可选的 XPBD 式边长投影，把每条边约束回材料静止长度的允许区间。物理
rollout 默认依靠 Hyper-NODE 屏障而不是它；开启时迭代次数和最大修正
（1.5 mm）都有上限。

## 7. 4D 神经场

物理“教师”轨迹（上面的显式仿真）先跑出若干帧，然后拟合一个
**E(3) 等变锚点场**（`e3_anchor_field.py`）：

```
x_q(t) = c̄_q + t·v_q(0) + B(ξ_q)·I(t)·d_q(t)
```

网络只输出标量（注意力、振幅）。所有 3D 向量都由相对位移、人体法向、人体
速度等极向量基合成，所以整个场景旋转平移后预测随之变换（实测等变误差约
1.2e-7 m）。训练损失包括轨迹误差、动力学平衡残差、自由边 traction、测度
连续性、哈密顿功率平衡与耗散符号（`variational_phase_pinn.py`、
`bundle_measure_port_hamiltonian.py`）。

日志里的 `cloth4d fit 0180/0180 batch=… temporal=…` 就是这一步。

## 8. 门禁（gates）

- **preflight**（`vto_preflight.py`）：进入物理之前检查语义关键点、受保护
  身体区域、遮挡顺序、尺寸分级、初始应变、接缝闭合、袖子覆盖。物理不负责
  修复一个错误的版型。
- **fit validation**：仿真后检查 p95 边长比 ≤ 1.2、穿插面比例 ≤ 0.5%、
  接缝间隙 ≤ 3 mm。

## 9. 简化路径（`physics.py`，MVP）

不带人体网格时用的轻量求解器：

- 重力；
- 余切 Laplacian 弯曲：作用于曲率**变化**；
- PBD 边长投影；
- 胶囊体人体代理碰撞。

它没有动量守恒的接触。在测量代理人体上，接缝间隙约 0.4 m，通不过自己的
门禁。这是流程限制，不是设计问题。

## 10. 一套服装的完整数据流

```
T 恤商品图 ──► run_mvp.py --fit-from-image ──► image_conditioned_tshirt_spec.json
                                                   │
Anny 人体 (export_anny_body_obj.py) ───────────────┼──► run_anny_cloth4d.py
                                                   │      隐式壳 T 恤 + 物理教师 + 4D 场
裙子商品图 ──► run_anny_pleated_skirt.py ───────────┤
                  环形百褶壳 + 物理教师 + 4D 场      │
                                                   ▼
                       run_unified_anny_cloth4d.py（两件衣服、一个时钟、层间接触、步行）
                                                   │
                       scripts/export_threejs_scene.py ──► web/scenes/<id>/*.f32|u32|png
                                                   │
                       anny-cloth-webgpu.html（Three.js WebGPURenderer）
                       scripts/capture_webgpu.mjs（无头 Chromium，验证 WebGPU 后端）
```

Agent 通过 `fashion` MCP 工具驱动这条链：`simulate_outfit` 跑物理，
`render_outfit` 出图。

## 11. 局限（必须如实说明）

- **未标定**：模量、阻尼、摩擦都是工程先验，需要 KES/FAB 实测或多运动数据才能
  辨识真实面料。
- **单视图不可辨识**：单张商品图只能给出类别、轮廓、褶数和外观；尺度来自人体。
- **接触覆盖不全**：人体接触是 SDF 顶点和面采样点，不是完整的 VF/EE CCD 或
  IPC。Genesis FEM + IPC 是计划中的高保真验证器，但需要 Linux 与 `pyuipc`。
- **时间窗口短**：已验证的演示窗口很短（0.16 s 至 2 s 的步行片段）。要延长，
  需要更好的层间接触，而不是放宽门禁。
